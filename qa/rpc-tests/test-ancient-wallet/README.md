# Zcashd "ancient" regtest test wallet fixture

Test fixture for `qa/rpc-tests/zcashd_key_import_ancient.py`.

This directory is intentionally a placeholder: the `wallet.dat`,
`full_manifest.json`, and `manifests/` files are **not yet committed**
because the wallet builder cannot produce this fixture until
<https://github.com/zcash/zcash/issues/7196> lands. Until then,
`zcashd_key_import_ancient.py` is listed in `DISABLED_SCRIPTS` in
`qa/pull-tester/rpc-tests.py` and is not run in CI.

## What this fixture is

A pre-Sapling, **HD-seedless** zcashd `wallet.dat`: a transparent-only
wallet with **no `hdseed` and no mnemonic**, generated by a pre-Sapling
zcashd binary (v1.0.15 / v1.1.1). Unlike the modern `../test-wallet`
fixture (which carries an HD seed and spans all network upgrades), this
wallet exercises zallet's seedless import path
(<https://github.com/zcash/wallet/issues/384>), where the migration
mints a fresh recovery seed to back the legacy transparent account.

Expected contents (per zcash/zcash#7196):

- a transparent coinbase UTXO,
- an `importprivkey` key (`transparent_privkey`),
- an `importpubkey` watch-only pubkey (`transparent_pubkey`),
- an `importaddress <redeemScript>` P2SH script (`transparent_p2sh`),
- optionally an `importaddress <addr>` watch-only-by-hash address
  (`transparent_watchonly`).

The manifest must follow the same schema as `../test-wallet`
(`full_manifest.json` + `manifests/phase_NN_*.json`), so the test can
reuse `load_manifest` / `load_phase_manifests`.

## Regenerating

1. Clone <https://github.com/zcash/zcash/tree/master/qa/zcash/wallet-builder>,
   note the exact commit hash you have checked out, then follow its
   README to build a fresh ancient wallet (the seedless / pre-Sapling
   mode added by zcash/zcash#7196).
2. Copy `wallet.dat`, `full_manifest.json`, and `manifests/` into this
   directory. **Record the builder commit hash from step 1 in the Source
   section above** — without it the fixture is not reproducible.
3. Remove `zcashd_key_import_ancient.py` from `DISABLED_SCRIPTS` in
   `qa/pull-tester/rpc-tests.py` (it also requires zallet's seedless
   import path, zcash/wallet#384, to be available in the `zallet` binary
   under test).
4. Run the test to confirm the fixture decodes cleanly:
   `python3 qa/rpc-tests/zcashd_key_import_ancient.py`.
